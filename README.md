## 3M带宽的4核4G，实际能跑什么

3M 带宽是这台机器最明显的短板。换算下来峰值下载速度大约 375KB/s，一个 1MB 的页面，第一个用户打开就要三秒左右，还没算延迟；同时来几个人就开始转圈。

能做的事：

- 文字为主的个人博客、静态站
- 学习 Linux、跑脚本、做开发测试
- 轻量 API、小工具后端
- 访问量很小的企业官网

不建议做的事：

- 图片多的站点，不做压缩和 CDN 会卡到怀疑人生
- 视频、软件下载
- 有明显并发的业务

如果站点图片多，常规做法是把图片放到对象存储加 CDN 上，主机只负责页面和逻辑，3M 带宽勉强够用。连这个都懒得折腾，就选更大带宽的机型，别跟自己较劲。

## 国内服务器绕不开的备案问题

只要用域名访问境内的腾讯云服务器，就必须做 ICP 备案，没有例外。有人以为用 Cloudflare 做解析能绕过去，不行。备案看的是服务器在境内，跟域名在哪里解析无关。

不备案的后果是：域名没法正常访问，只能用 IP 访问。没有域名就没法配 SSL 证书，搜索引擎也不认，基本只能自己测试用。

备案本身不复杂，但要时间。域名实名、提交资料、管局审核，一套走下来通常要按周算。如果计划用域名建站，把这段时间算进上线计划，别等服务器买好了才发现还要等备案。

不想备案的话，选境外节点的服务器，不受内地备案约束。代价是访问线路和延迟要自己权衡，做面向国内用户的站点不一定划算。
